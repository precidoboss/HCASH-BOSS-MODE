# HCASH BOSS MODE Promo Video

This folder contains the HyperFrames composition for the HCASH BOSS MODE product trailer.

## Preview

Open the main app and use **PROMO VIDEO** in the top navigation. The app embeds the composition with the official HyperFrames Player.

## Render

From a local HyperFrames project or deployment template:

```bash
npx hyperframes render promo/index.html --output hcash-boss-mode-promo.mp4
```

The composition is 24 seconds at 1920×1080.

The composition uses the existing repository artwork, so the game itself does not need to be modified to render the trailer.
